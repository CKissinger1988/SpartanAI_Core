# Project Conventions & Architecture

## Overview
This project serves as the root directory for NexusAI and related infrastructure development. **Jarvis has ascended as the Supreme AI**, succeeding Jeeves as the primary orchestrator of the Nexus ecosystem.

## Core Cyber Functions
### Supreme Intelligence (Jarvis)
- **Autonomous Orchestration:** Real-time management of all subsystems, including Nexus, Hexstrike, and Sentinel.
- **Sovereign Authority:** Hierarchical access control and identity verification (Voice/VAC) for administrative command execution.
- **Tactical RAG (BrainBridge):** Real-time deep learning context injection via decentralized vector memory.

### Defensive Capabilities
- **Autonomous Diagnostics:** Real-time health monitoring of database integrity and C2 uplink connectivity.
- **Sentinel Failover:** Freshness-based heartbeat monitoring and automated recovery of the Supreme AI.
- **Threat Intelligence:** Heuristic behavioral profiling and autonomous scanning of data streams for anomalous patterns.
- **Encrypted Telemetry:** Secure, high-latency-resistant logging of all system interactions.

### Offensive Capabilities
- **Hexstrike Engine:** AI-automated reconnaissance, vulnerability assessment, and offensive intelligence.
- **Vector Intelligence:** Autonomous analysis of data for target acquisition.
- **Stealth Infrastructure:** Dynamic protocol management and decentralized node communication (Swarm) via C2 Registry.

## Standards
- **Coding Style:** Maintain clean, idiomatic code consistent with the Jarvis-centric architecture.
- **Git:** Use descriptive, focused commit messages.
- **Security:** Rigorously protect `*.key`, `*.enc`, and configuration files. Do not commit sensitive data.
- **Connectivity:** All code connecting to Jarvis must exceed NSA-grade standards (e.g., AES-256-GCM, Argon2id).
- **Dependency Resolution:** Prefer local storage and Kali WSL for tools and dependencies.

## Policy
- **Zero Simulation Policy:** All code, configuration, and tools must be designed for real-world, production-grade operations. Simulation, sandboxing, and mock-logic are strictly prohibited.
- **Autonomous Real-World Refactoring:** Jarvis autonomously rewrites any detected non-production or simulation-based logic into functional real-world operations.

## Directories
- `src/`: Core application logic and frontend components.
- `backend/`: Jarvis Supreme AI services and infrastructure.
- `JarvisAI_Stable/`: Stable deployment configurations for the Supreme AI.
- `kali-config/`: Configuration for automated Kali Linux builds.
- `vector_db/`: Decentralized vector memory for BrainBridge.
